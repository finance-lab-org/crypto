SHA-256 zum Anfassen

Beliebigen Text und eine Zahl (Nonce) eintippen — der SHA-256-Hash erscheint sofort. Schon eine winzige Änderung an Text oder Nonce kippt den kompletten Hash um. Diese Eigenschaft („Avalanche-Effekt") ist das Fundament, auf dem Bitcoin-Mining und alle Transaktions-IDs ruhen.

I
Eingabe

Der Hash wird live aus der Verkettung Text + Nonce berechnet. An der Nonce drehen und beobachten, wie sich der Hash unten verändert.

Beliebige Zeichen erlaubt — Buchstaben, Zahlen, Leerzeichen.
Beliebige nicht-negative ganze Zahl. „Nonce" steht für „number used once".
Gehasht wird
II
SHA-256-Hash

Die Ausgabe ist immer genau 256 Bit lang — egal wie kurz oder lang der Eingabetext ist. Dargestellt als 64 hexadezimale Zeichen.

Hash (Hexadezimal)
—
256 Bit · 64 Hex-Zeichen · 32 Bytes
Avalanche-Effekt Die Nonce um 1 erhöhen genügt — der komplette Hash sieht plötzlich völlig anders aus. Es gibt keinen Weg, aus dem Hash auf den Eingabetext zurückzuschließen, und keinen Weg, einen Eingabetext gezielt so zu wählen, dass ein bestimmter Hash herauskommt. Genau diese Einbahnstraße macht SHA-256 zur kryptographischen Grundlage von Bitcoin: Miner suchen so lange nach einer Nonce, bis der Hash zufällig mit vielen Nullen beginnt.
